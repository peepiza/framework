# Сервис планирования репетиций

Консольное приложение для учёта музыкальных групп, участников
и бронирования помещений под репетиции.

## Возможности
- просмотр и добавление групп;
- просмотр участников группы;
- просмотр, поиск и сортировка помещений;
- проверка вместимости помещения;
- проверка доступности помещения и группы на дату;
- создание и отмена репетиций;
- сохранение данных в JSON-файлах.

## Структура проекта
- main.py — точка запуска и меню;
- bands.py — работа с группами;
- members.py — работа с участниками;
- rooms.py — работа с помещениями;
- rehearsals.py — работа с репетициями;
- storage.py — сохранение и загрузка JSON;
- utils.py — безопасный ввод;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты pytest.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python3 main.py

## Запуск тестов

    pytest

## Проверка качества кода

    flake8
