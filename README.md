# Сервис планирования репетиций

## Назначение
Приложение предназначено для планирования репетиций музыкальных групп:
проверки доступности помещения, согласования времени и учёта занятости участников.

## Целевая аудитория
Руководители и администраторы музыкальных групп, ансамблей и коллективов.

## Предметная область
Организация репетиционного процесса музыкальных групп: расписание, помещения, участники.

## Основные сущности
- Музыкальная группа
- Участник
- Помещение
- Репетиция

## Основные функции
- Проверка доступности помещения на выбранную дату
- Проверка свободного времени участников группы
- Формирование решения о проведении репетиции

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
