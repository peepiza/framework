# Сервис планирования репетиций

Приложение для музыкальных групп, позволяющее управлять помещениями и планировать репетиции. 
Проект прошел путь от консольного скрипта до объектно-ориентированного приложения с веб-интерфейсом.

## Используемые технологии
* **Python 3** — основной язык разработки.
* **Django 5.2** — веб-фреймворк для создания серверной части и маршрутизации.
* **HTML / CSS / Bootstrap 5.3** — создание и оформление веб-интерфейса.
* **JSON** — временное хранилище данных (на данном этапе).
* **pytest** — автоматизированное тестирование.
* **flake8** — проверка качества и стиля кода (PEP 8).

## Возможности проекта

### Веб-интерфейс (ПР5)
* Просмотр списка всех помещений.
* Просмотр детальной информации о помещении (вместимость, адрес).
* Проверка доступности помещения на текущую дату.
* Просмотр списка всех репетиций.
* Просмотр детальной информации о репетиции (группа, помещение, время, статус).
* Кастомная страница ошибки 404.
* Навигация между разделами сайта.

### Консольный интерфейс (сохранен с ПР1–ПР3)
* Добавление групп и участников.
* Добавление и поиск помещений.
* Бронирование и отмена репетиций.
* Сохранение данных в JSON-файлы.

## Основные классы предметной области (`models/`)
* `Room` (помещение) — атрибуты: `id`, `name`, `capacity`, `address`; методы: `is_suitable_for()`, `__str__`.
* `Band` (группа) — атрибуты: `id`, `name`, `genre`, `members_count`.
* `Member` (участник) — атрибуты: `id`, `name`, `instrument`, `band_id`.
* `Rehearsal` (репетиция) — атрибуты: `id`, `band`, `room`, `rehearsal_date`, `start_time`, `is_cancelled`; метод: `cancel()`.
