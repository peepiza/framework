# Сервис планирования репетиций

Консольное приложение для учёта музыкальных групп, участников
и бронирования помещений под репетиции.

## Возможности

- просмотр и добавление групп;
- просмотр участников группы;
- просмотр, поиск и сортировка помещений;
- проверка вместимости помещения;
- проверка доступности помещения и группы на дату;
- создание и отмена репетиций;
- сохранение данных в JSON-файлах.

## Основные классы

### Band — музыкальная группа

Атрибуты: `id`, `name`, `genre`, `members_count`.

Методы:
- `__init__` — создание объекта;
- `__str__` — строковое представление;
- `from_data` — создание объекта из словаря JSON.

### Member — участник группы

Атрибуты: `id`, `name`, `instrument`, `band_id`.

Методы: `__init__`, `__str__`, `from_data`.

### Room — помещение

Атрибуты: `id`, `name`, `capacity`, `address`.

Методы:
- `__init__`, `__str__`, `from_data`;
- `is_suitable_for(people_count)` — проверка вместимости;
- `validate_capacity(capacity)` — статическая проверка корректности значения.

### Rehearsal — репетиция

Атрибуты: `id`, `band` (объект `Band`), `room` (объект `Room`),
`rehearsal_date`, `start_time`, `is_cancelled`.

Методы:
- `__init__`, `__str__`, `from_data`;
- `cancel()` — отмена репетиции (устанавливает `is_cancelled = True`).

## Взаимодействие объектов

Объект `Rehearsal` хранит ссылки на объекты `Band` и `Room`.
Отменённая репетиция не удаляется из коллекции, а помечается
флагом `is_cancelled` и перестаёт блокировать помещение на дату.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python3 main.py

    pytest -v
